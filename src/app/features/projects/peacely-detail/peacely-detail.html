Peacely

A minimalist Garmin watch face built with Monkey C and Connect IQ, featuring configurable themes, time formats, and activity metrics in a calm, distraction-free design.

View on Connect IQ Store

Overview

Peacely is a minimalist Garmin watch face designed for everyday glanceability. It combines large readable time, soft watercolor-inspired backgrounds, and simple wellness metrics in a calm wearable interface.

The project explores how a watch face can remain useful without becoming visually busy. Rather than displaying numerous metrics at once, Peacely focuses on the information most people check throughout the day: time, date, battery status, and a single activity metric.

Built with Garmin Connect IQ and Monkey C, the watch face includes configurable settings for theme selection, 12-hour or 24-hour time formats, and an optional bottom metric that can display either daily steps or heart rate.

Published on the Garmin Connect IQ Store and available for download.

Themes

Peacely includes three visual themes that share the same layout while offering different visual moods.

Sage

A soft green theme inspired by calm nature and everyday readability.

Warm

A gentle beige theme with a cozy paper-like feeling.

Night

A dark, low-distraction theme for strong contrast and low-light use.

Features

  • Readable time display
    Large centered time designed for quick glances.
  • Essential status info
    Date and battery percentage are visible without crowding the screen.
  • Steps or heart rate
    Users can choose between daily steps and heart rate from the Connect IQ settings screen.
  • Theme options
    Sage, Warm, and Night themes use custom background assets and matching icon colors.
  • Time format support
    Supports both 24-hour and 12-hour time display.

Tech

Peacely is implemented as a Garmin Connect IQ watch face using Monkey C and is supported and tested on the Garmin Venu 2 series.

  • Monkey C + Connect IQ SDK
    Built with Garmin's native watch face tooling.
  • Custom theme system
    Uses theme constants, bitmap backgrounds, and matching icon resources.
  • Dynamic metric row
    Centers icon and value together so steps and heart rate remain balanced across different values.
  • Connect IQ settings
    Implemented Connect IQ settings allowing users to switch themes, choose the displayed metric, and toggle between 12-hour and 24-hour time formats.
  • Device support
    Currently supported and tested on the Garmin Venu 2 series (Venu 2 Plus, Venu 2, and Venu 2S).
