PengPhin Adventures

A bilingual Angular memory game designed for children, combining themed worlds, interactive audio, progression systems, responsive gameplay, and mascot-driven storytelling.

Play the Game

Overview

PengPhin Adventures is a bilingual educational memory game created both as a playful experience for children and as a frontend-focused Angular project exploring responsive gameplay, interactive audio, progression systems, localization, and game-oriented UI design.

The project started as a way to build something meaningful and fun for my child, then evolved into a fully featured educational game with themed worlds, bilingual content, localized audio, progression systems, special card mechanics, mascot interactions, and responsive gameplay.

Players join two mascots — Peng the penguin and Phin the dolphin — as they travel through six themed worlds, discover animals, listen to localized voice interactions, collect rewards, and unlock increasingly challenging levels.

Gameplay

The gameplay is based on classic memory matching: players flip cards, discover pairs, and clear the board while progressing through increasingly playful worlds and mechanics.

While the interaction remains simple and accessible, surrounding systems such as coins, hints, localized audio, mascot reactions, progression, and special cards create a richer and more rewarding experience for young players.

The game was continuously refined around gameplay clarity, pacing, interaction feedback, and board complexity across different screen sizes and difficulty levels.

  • Accessible gameplay loop
    Simple matching interactions designed to feel intuitive and easy to understand.
  • Reward-focused feedback
    Coins, reactions, and progression systems help each round feel satisfying and engaging.
  • Balanced challenge
    Hint systems and progressive mechanics help maintain accessibility without removing challenge.
  • Interactive audio experience
    Animals, mascots, and special cards include localized English and Bulgarian voice interactions.
  • Real user testing
    Gameplay, progression, and interaction design were continuously refined through testing with a young player.

Worlds

PengPhin Adventures is organized around themed worlds that create a sense of progression and exploration beyond a traditional memory game.

Each world introduces its own atmosphere, visual identity, and gameplay mood while keeping the core interaction familiar and easy to understand.

The structure includes playful environments such as Ocean, Farm, Jungle, Arctic, Dinosaur, and Space, helping progression feel like a continuous adventure.

Each world includes unique animals, mascots, visual themes, audio content, special-card personalities, and localized interactions.

  • Themed progression
    Worlds help transform simple memory gameplay into a broader adventure structure.
  • Global level system
    Progression continues across worlds instead of resetting between themes.
  • Visual variety
    Backgrounds, board styling, and colors evolve between worlds.

Mechanics

Beyond traditional matching mechanics, the game introduces systems designed to create surprise, replay value, and personality.

Bonus cards reward players with extra coins, while Mischief cards introduce playful disruption by moving hidden cards or changing board expectations during gameplay.

These mechanics were intentionally designed to stay understandable for young children while introducing surprise, replayability, and progression throughout the adventure.

  • Bonus & Mischief cards
    Special cards add playful unpredictability and reward moments.
  • Hint system
    Optional assistance helps players continue without frustration.
  • Mascot interaction
    Peng and Phin provide visual feedback and emotional engagement during gameplay.
  • Localized voice interactions
    Discovered animals and special cards can be tapped to hear spoken introductions and character dialogue.

Design

The visual direction focuses on soft shapes, playful colors, and a welcoming atmosphere designed to feel friendly and approachable.

Special attention was given to responsive behavior. The game board adapts across mobile, tablet, and desktop while balancing card sizing, spacing, and gameplay clarity.

Character placement, UI layering, and board scaling were carefully adjusted to preserve personality without overwhelming the gameplay area.

  • Playful visual identity
    Mascots, themed worlds, and soft shapes give the game personality.
  • Adaptive board scaling
    Boards dynamically adjust rows, columns, spacing, and card sizing across devices and orientations.
  • Clear interaction hierarchy
    Gameplay remains understandable even as mechanics and progression expand.

Tech

PengPhin Adventures was built using Angular, TypeScript, and SCSS with a component-based architecture focused on reusable gameplay systems and responsive UI behavior.

World progression, special mechanics, card generation, scoring, and unlock logic are handled through structured TypeScript state and configuration-driven game data.

The project includes a localized audio system with recorded English and Bulgarian voice lines for animals, mascots, and special cards, creating a more engaging experience for young players.

Core gameplay systems are supported by automated unit tests covering board generation, language switching, audio management, and component initialization.

  • Angular architecture
    Standalone components organize gameplay, worlds, UI systems, and progression flows.
  • Configuration-driven structure
    Worlds, themes, levels, and mechanics are managed through reusable configuration models.
  • Responsive SCSS system
    Layouts scale across mobile, tablet, and desktop while preserving gameplay usability.
  • Localized audio system
    Recorded English and Bulgarian voice assets provide feedback and educational reinforcement.
  • Automated testing
    Unit tests cover gameplay services, language management, audio controls, and core component initialization.
  • Progressive Web App (PWA)
    Installable experience with offline support, app-like navigation, and mobile-friendly deployment.

Testing

The project includes automated unit tests focused on core gameplay systems and supporting services.

Testing covers board generation, animal pair creation, language switching, audio controls, and component initialization.

  • Board generation tests
    Verify correct card counts, animal pairs, bonus cards, and special cards.
  • Language service tests
    Validate localization and English/Bulgarian switching behaviour.
  • Audio service tests
    Verify sound settings and audio management logic.
  • Component tests
    Validate successful creation and initialization of core game components.
